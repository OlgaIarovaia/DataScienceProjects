# DataScienceProjects
Краткое содержание и описание проектов, собранных в процессе обучения на DataScience - от аналитики до ML.

## 01. ANALYTICS_MUSIC
### Цель проекта
Сравнение предпочтений пользователей сервиса Яндекс.Музыка в Москве и Санкт-Петербурге
### Методология
Библиотека pandas.   \
Аналитика - изучение массива данных и выявление закономерностей (топ, частота и прочее)

## 02. ANALYTICS_BANK
### Цель проекта
Выяснить есть ли зависимость между возвратом кредита в срок и различными факторами
### Методология
Библиотеки pandas, seaborn, matplotlib.   \
Предобработка - работа с пропусками (в т.ч заполнение медианами по срезам), категоризация данных.  \
Аналитика - подсчет показателей, вывод диаграмм для визуализации и выводы.  \

## 03. ANALYTICS_REALTY
### Цель проекта
Ознакомиться, предобработать и изучить данные продаж недвижимости за несколько лет:  \
- Выделить особенности недвижимости.
- Выяснить, как быстро продавалась недвижимость и какие факторы больше всего влияют на ее цену.
- Узнать среднюю цену кв.м. недвижимости в 10 самых продаваемых населенных пунктах и среднюю цену км. в удаленности от центра города.
### Методология
Библиотеки pandas, matplotlib.  \
Предобработка - работа с аномалиями, пропусками и дубликатами, корректировка типов данных, добавление новых срезов для аналитики.  \
Аналитика - изучение параметров, визуализация и выводы.

## 03. ANALYTICS_PHONE
### Цель проекта
Проанализировать поведение клиентов и сделать вывод — какой тариф рентабельней.  \
Проверить гипотезы о равенстве средних затрат между группами пользователей с оценкой статистической значимости.
### Методология
Библиотеки pandas, numpy, seaborn, matplotlib,stats.  \
Предобработка - работа с типами данных, добавление новых срезов для аналитики.  \
Аналитика - изучение параметров, визуализация и выводы.
