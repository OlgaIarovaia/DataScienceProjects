# DataScienceProjects
Краткое содержание и описание проектов, собранных в процессе обучения на DataScience - от аналитики до ML.

Структура:
 - projects - Python-код по конкретной, смотри описание ниже.
 - theoty - Краткая теория по части тем.

Библиотека pandas.   \
Аналитика - изучение массива данных и выявление закономерностей (топ, частота и прочее)


## 02. ANALYTICS_BANK

## 03. ANALYTICS_REALTY
### Цель проекта
Ознакомиться, предобработать и изучить данные продаж недвижимости за несколько лет:  
- Выделить особенности недвижимости.
- Выяснить, как быстро продавалась недвижимость и какие факторы больше всего влияют на ее цену.
- Узнать среднюю цену кв.м. недвижимости в 10 самых продаваемых населенных пунктах и среднюю цену км. в удаленности от центра города.
### Методология
Библиотеки pandas, matplotlib.  \
Предобработка - работа с аномалиями, пропусками и дубликатами, корректировка типов данных, добавление новых срезов для аналитики.  \
Аналитика - изучение параметров, визуализация и выводы.

## 05. ML_TARIFF
### Цель проекта
Выбрать лучшую классическую ML-модель и подобрать ей оптимальные гиперпараметры. Задача модели - подбор подходящего клиенту тарифа.
### Методология
Библиотеки pandas, seaborn, sklearn.   \
Модели Логистической регрессии, Дерева решений и Случайного леса.  \
Предобработка - разделение данных на обучающую, тестовую и валидационную выборки.  \
ML - обучение 3 типов моделей с разными параметрами. Выбор лучшего набора параметров для каждой модели, затем выбор лучшей модели.  \
Улучшение качества, сравнение качества лучшей модели с базовой DummyClassifier для получения вывода о целесообразности использования модели в работе.


## 06. ML_LEAVE_BANK
### Цель проекта
Спрогнозировать, уйдёт ли клиент из банка в ближайшее время.
### Методология
Библиотеки pandas, numpy, sklearn.  \
Модели Логистической регрессии, Дерева решений и Случайного леса, методы баланса классов - самообучение (class_weight=balanced) и downsampling.  \
Предобработка - работа с категориальными переменными; разделение данных на обучающую, тестовую и валидационную выборки.  \
ML - обучение 3 типов моделей с разными параметрами. Выбор лучшего набора параметров для каждой, затем выбор лучшей модели.  \
Метрики качества F1-мера и AUC-ROC. Обучение модели без учёта и с учетом дисбаланса классов.


## 07. ML_BOREHOLE
### Цель проекта
Принять решение, где бурить новую скважину. Построить модель для определения региона, где добыча принесёт наибольшую прибыль.
Проанализировать возможную прибыль и риски техникой Bootstrap.
### Методология
Библиотеки pandas, numpy, seaborn, matplotlib.pyplot, sklearn, scipy.  \
Модель Линейной регрессии и техника Bootstrap, а также доверительный интервал (средняя прибыль).  \
Предобработка - проверка данных, изучение корреляции, удаление дубликатов.  \
ML - обучение модели с метрикой качества RMSE.  \
Аналитика - расчет прибыли (хардово предсказанной и скорректированной с помощью Bootstrap), расчет доверительного среднего для прибыли, расчет риска (доля отрицательной прибыли)


## 08. ML_LINEAR_ALGEBRA
### Цель проекта
Необходимо защитить данные клиентов:
- разработать метод преобразования данных, по которому было бы сложно восстановить персональную информацию.
- обосновать корректность работы метода.
- при преобразовании качество модели не должно ухудшаться.
  
Предложенный алгоритм должен быть:
- доказан теоритически (с помощью формул линейной регрессии)
- проверен практически (провести обучение на изначальных и преобразованных данных - метрики качества должны совпадать)

### Методология
Библиотеки pandas, seaborn, numpy, sklearn.  \
Глубокая работа с моделью Линейной регрессии, в том числе работу с весами и предсказаниями по формулам. В проекте используется метод Pipeline и работа с матрицами.  \
Предобработка - проверка данных, работа с типами данных.  \
ML - обучение модели с учетом стандартизации  \
Дополнительно - математическое доказательство и проверка неизменности качества линейной регрессии на реальных данных, если алгоритм защиты - умножение признаков на обратимую рандомную матрицу
