# DataScienceProjects
Краткое содержание и описание проектов, собранных в процессе обучения на DataScience - от аналитики до ML.

## 01. ANALYTICS_MUSIC
### Цель проекта
Сравнение предпочтений пользователей сервиса Яндекс.Музыка в Москве и Санкт-Петербурге
### Методология
Библиотека pandas.   \
Аналитика - изучение массива данных и выявление закономерностей (топ, частота и прочее)

## 02. ANALYTICS_BANK
### Цель проекта
Выяснить есть ли зависимость между возвратом кредита в срок и различными факторами
### Методология
Библиотеки pandas, seaborn, matplotlib.   \
Предобработка - работа с пропусками (в т.ч заполнение медианами по срезам), категоризация данных.  \
Аналитика - подсчет показателей, вывод диаграмм для визуализации и выводы.  \

## 03. ANALYTICS_REALTY
### Цель проекта
Ознакомиться, предобработать и изучить данные продаж недвижимости за несколько лет:  \
- Выделить особенности недвижимости.
- Выяснить, как быстро продавалась недвижимость и какие факторы больше всего влияют на ее цену.
- Узнать среднюю цену кв.м. недвижимости в 10 самых продаваемых населенных пунктах и среднюю цену км. в удаленности от центра города.
### Методология
Библиотеки pandas, matplotlib.  \
Предобработка - работа с аномалиями, пропусками и дубликатами, корректировка типов данных, добавление новых срезов для аналитики.  \
Аналитика - изучение параметров, визуализация и выводы.

## 04. ANALYTICS_PHONE
### Цель проекта
Проанализировать поведение клиентов и сделать вывод — какой тариф рентабельней.  \
Проверить гипотезы о равенстве средних затрат между группами пользователей с оценкой статистической значимости.
### Методология
Библиотеки pandas, numpy, seaborn, matplotlib,stats.  \
Предобработка - работа с типами данных, добавление новых срезов для аналитики.  \
Аналитика - изучение параметров, визуализация и выводы.

## 05. ML_TARIFF
### Цель проекта
Выбрать лучшую классическую ML-модель и подобрать ей оптимальные гиперпараметры. Задача модели - подбор подходящего клиенту тарифа.
### Методология
Библиотеки pandas, seaborn, sklearn. Модели Логистической регрессии, Дерева решений и Случайного леса.  \
Предобработка - разделение данных на обучающую, тестовую и валидационную выборки.  \
ML - обучение 3 типов моделей с разными параметрами. Выбор лучшего набора параметров для каждой модели, затем выбор лучшей модели.  \
Улучшение качества, сравнение качества лучшей модели с базовой DummyClassifier для получения вывода о целесообразности использования модели в работе.

## 06. ML_LEAVE_BANK
### Цель проекта
Спрогнозировать, уйдёт ли клиент из банка в ближайшее время.
### Методология
Библиотеки pandas, numpy, sklearn. Модели Логистической регрессии, Дерева решений и Случайного леса, методы баланса классов - самообучение (class_weight=balanced) и downsampling.  \
Предобработка - работа с категориальными переменными; разделение данных на обучающую, тестовую и валидационную выборки.  \
ML - обучение 3 типов моделей с разными параметрами. Выбор лучшего набора параметров для каждой, затем выбор лучшей модели.  \
Метрики качества F1-мера и AUC-ROC. Обучение модели без учёта и с учетом дисбаланса классов.
