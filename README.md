# DataScienceProjects
Краткое содержание и описание проектов, собранных в процессе обучения на DataScience - от аналитики до ML.

Структура:
 - projects - Python-код по конкретной, смотри описание ниже.
 - theoty - Краткая теория по части тем.

## Сборные проекты
### 001. ANALYTICS_GAMES
#### Цель проекта
Выявить определяющие успешность игры закономерности для вывода потенциально популярного продукта и планирования рекламных кампаний.   \
Проект основан на таблице с данными об играх за 1980-2016 гг; прогноз необходим на 2017 год.

Проверить гипотезы:
- Средние пользовательские рейтинги двух платформ одинаковые
- Средние пользовательские рейтинги жанров одинаковые
#### Методология
Библиотеки pandas, seaborn, matplotlib.pyplot, scipy.   \
Предобработка - работа с типами данных и пропусками, добавление новых срезов.

Аналитика
- Динамика выпуска игр
- Платформы для игр: самые популярные, частота появления новых
- Влияние факторов на продажи: отзывы, жанр
- Отличие продаж по регионам: платформы, жанры, рейтинг ESRB
- Выбор периода и проверка гипотез
- Выводы

### 002. ML_GOLD_MINING
#### Цель проекта
Вывести модель, которая должна будет предсказать коэффициент восстановления золота из золотосодержащей руды и поможет оптимизировать производство, чтобы не запускать предприятие с убыточными характеристиками.   \
Конечная метрика качества — sMAPE (симметричное среднее абсолютное процентное отклонение) включит в себя эффективность обогащения чернового концентрата и финального концентрата.

#### Методология
Библиотеки pandas, matplotlib.pyplot, numpy, sklearn.   \
Модели Дерево решений, Случайный лес, Линейная регрессия.   \
Предобработка - проверка корреляции признаков, исключение части признаков, работа с пропусками и дубликатами, масштабирование признаков.   \
Аналитика - сравнение изменения концентрации металлов (Au, Ag, Pb),  суммарная концентрация веществ на различных этапах очистки, оценка распределения размера гранул сырья обучающей и тестовой выборки и вывод о том, можно ли будет доверять оценке модели.   \
ML - написание функции для кастомной метрики качества, разделение обучения на 2 этапа (по аналогии с техническими особенностями работы с металлами), подбор лучших параметров для каждой модели с помощью кросс-валидации GridSearchCV и выбор лучшей модели.

### 08. ML_LINEAR_ALGEBRA
#### Цель проекта
Необходимо защитить данные клиентов:
- разработать метод преобразования данных, по которому было бы сложно восстановить персональную информацию.
- обосновать корректность работы метода.
- при преобразовании качество модели не должно ухудшаться.
  
Предложенный алгоритм должен быть:
- доказан теоритически (с помощью формул линейной регрессии)
- проверен практически (провести обучение на изначальных и преобразованных данных - метрики качества должны совпадать)

#### Методология
Библиотеки pandas, seaborn, numpy, sklearn.  \
Глубокая работа с моделью Линейной регрессии, в том числе работу с весами и предсказаниями по формулам. В проекте используется метод Pipeline и работа с матрицами.  \
Предобработка - проверка данных, работа с типами данных.  \
ML - обучение модели с учетом стандартизации  \
Дополнительно - математическое доказательство и проверка неизменности качества линейной регрессии на реальных данных, если алгоритм защиты - умножение признаков на обратимую рандомную матрицу
